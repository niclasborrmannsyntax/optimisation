# SEO Leitfaden für Webseiten

## 1. Was ist SEO?

SEO (Search Engine Optimization) bedeutet, eine Seite so zu optimieren, dass sie in Suchmaschinen besser gefunden, besser verstanden und häufiger geklickt wird.

Ziele von SEO:

- Mehr qualifizierter organischer Traffic
- Bessere Sichtbarkeit für relevante Suchbegriffe
- Mehr Conversions (z. B. Leads, Käufe, Anfragen)

Wichtige Bereiche:

- Onpage SEO: Inhalt, Struktur, Meta-Daten, interne Verlinkung
- Technisches SEO: Ladezeit, Crawlbarkeit, Indexierung, Schema Markup
- Offpage SEO: Backlinks, Marken-Signale

## 2. Keyword- und Intent-Analyse

### Schritt 1: Hauptkeyword definieren

- Pro Seite ein primäres Hauptkeyword
- Zusätzlich 3-10 Nebenkeywords (Synonyme, Long-Tail, Fragen)

### Schritt 2: Suchintention (Search Intent) bestimmen

- Informational: Nutzer sucht Wissen (z. B. "was ist seo")
- Navigational: Nutzer sucht eine konkrete Marke/Seite
- Transactional: Nutzer will kaufen/buchen
- Commercial Investigation: Nutzer vergleicht Lösungen

Regel:

- Der Seiteninhalt muss zur Suchintention passen. Sonst rankt die Seite trotz guter Technik oft nicht stabil.

## 3. URL-Struktur und Seitenarchitektur

### Gute URL-Merkmale

- Kurz und lesbar
- Enthalten das Hauptkeyword
- Kleinschreibung, Bindestriche statt Unterstriche
- Keine unnötigen Parameter

Beispiel:

- Gut: /seo-audit-checkliste
- Schlecht: /page?id=123&ref=abc

### Informationsarchitektur

- Klare Hierarchie (Startseite -> Kategorie -> Detailseite)
- Wichtige Seiten max. 3 Klicks von der Startseite entfernt
- Sinnvolle interne Verlinkung zwischen thematisch nahen Seiten

## 4. Title Tag optimieren

Der Title Tag ist eines der wichtigsten Onpage-Signale.

Empfehlungen:

- Länge: ca. 50-60 Zeichen
- Hauptkeyword möglichst weit vorne
- Klarer Nutzen oder Differenzierung
- Jede Seite braucht einen einzigartigen Title

Formel:

- Hauptkeyword | Nutzenversprechen | Marke

Beispiel:

- SEO Audit für KMU | Klare Prioritäten in 7 Tagen | NeuralFlow

## 5. Meta Description optimieren

Die Meta Description ist kein direktes Ranking-Signal, beeinflusst aber die Klickrate (CTR).

Empfehlungen:

- Länge: ca. 140-160 Zeichen
- Problem + Nutzen + Call-to-Action
- Hauptkeyword natürlich integrieren
- Pro Seite einzigartig

Beispiel:

- Erhalte ein praxisnahes SEO Audit mit klaren Prioritäten. Finde technische Fehler, Content-Lücken und schnelle Quick Wins für mehr organischen Traffic.

## 6. Überschriften (H1-H6) korrekt einsetzen

Regeln:

- Genau eine H1 pro Seite
- H1 enthält Hauptkeyword oder enge Variante
- H2/H3 strukturieren Themen logisch
- Keine Überschriften nur für Styling verwenden

Nutzen:

- Bessere Lesbarkeit für Nutzer
- Klarere semantische Struktur für Suchmaschinen

## 7. Content-Qualität und Relevanz

### Anforderungen an starken SEO-Content

- Beantwortet die Suchintention vollständig
- Liefert konkrete, belastbare Informationen
- Ist aktuell, korrekt und gut strukturiert
- Nutzt Beispiele, Daten, Schrittfolgen, FAQ

### E-E-A-T orientiert schreiben

- Experience: Eigene praktische Erfahrung zeigen
- Expertise: Fachkompetenz belegen
- Authoritativeness: Seriöse Quellen, klare Positionierung
- Trustworthiness: Transparenz, Impressum, Datenschutz, klare Autoren

### Keyword-Einsatz

- Hauptkeyword in H1, ersten Abschnitten, Title, URL
- Nebenkeywords natürlich im Fließtext
- Kein Keyword Stuffing

## 8. Interne Verlinkung

Warum wichtig:

- Verteilt Linkkraft innerhalb der Website
- Hilft Suchmaschinen beim Crawling
- Führt Nutzer tiefer in relevante Inhalte

Best Practices:

- Kontextbezogene Links im Fließtext
- Aussagekräftige Anchor-Texte (nicht nur "hier klicken")
- Wichtige Seiten regelmäßig von starken Seiten verlinken

## 9. Bilder-SEO

Pflichtpunkte:

- Dateiname beschreibend (z. B. seo-audit-dashboard.jpg)
- Alt-Text sinnvoll und knapp
- Moderne Formate (WebP/AVIF)
- Bildgrößen und Kompression optimieren
- Lazy Loading für nicht sofort sichtbare Bilder

## 10. Technisches SEO

### Core Web Vitals (wichtig für UX und Ranking)

- LCP (Largest Contentful Paint): Ziel <= 2.5 s
- INP (Interaction to Next Paint): Ziel <= 200 ms
- CLS (Cumulative Layout Shift): Ziel <= 0.1

### Weitere Technik-Faktoren

- Mobile First: Seite muss mobil exzellent funktionieren
- HTTPS aktiv
- Saubere HTML-Struktur
- Keine kaputten Links (404) in wichtigen Bereichen
- Redirects korrekt (301 statt 302 bei permanenten Umzügen)

## 11. Indexierung und Crawlbarkeit

### Robots.txt

Steuert, was Bots crawlen dürfen.

- Wichtige Inhalte nicht versehentlich blockieren
- Admin-/Systempfade bei Bedarf ausschließen

### Meta Robots

- index, follow: Standard für normale Seiten
- noindex, nofollow: Für Seiten, die nicht in Google erscheinen sollen

### XML Sitemap

- Enthalten sein sollten indexierbare, kanonische Seiten
- Regelmäßig aktualisieren
- In Google Search Console einreichen

### Canonical Tag

- Verhindert Duplicate-Content-Probleme
- Zeigt Suchmaschinen die bevorzugte URL-Version

## 12. Strukturierte Daten (Schema Markup)

Ziel:

- Suchmaschinen geben Inhalte besser einordnen
- Chance auf Rich Results (z. B. FAQ, Product, Article)

Übliche Typen:

- Organization
- WebSite
- BreadcrumbList
- Article
- Product
- FAQPage

Format:

- JSON-LD wird empfohlen

## 13. Social Meta Tags (Open Graph / Twitter)

Diese Tags beeinflussen Linkvorschauen in Social Media.

Wichtige Felder:

- og:title
- og:description
- og:type
- og:url
- og:image
- twitter:card
- twitter:title
- twitter:description
- twitter:image

Hinweise:

- Nutze absolute Bild-URLs
- Social Preview Bild in guter Qualität bereitstellen

## 14. Lokales und internationales SEO (falls relevant)

Lokales SEO:

- Google Business Profile pflegen
- Konsistente NAP-Daten (Name, Address, Phone)
- Lokale Landingpages mit echten Standortinfos

Internationales SEO:

- hreflang für Sprach-/Ländervarianten
- Klare Trennung von Sprachversionen
- Sprachgerechte Inhalte statt automatischer 1:1 Übersetzung ohne Qualitätskontrolle

## 15. Messen, Monitoring, Iteration

Wichtige Tools:

- Google Search Console: Rankings, Indexstatus, CTR, technische Probleme
- Web Analytics: Verhalten, Conversions, Landingpage-Performance
- Crawling-Tools: technische Fehler, Duplicate Content, Meta-Probleme

KPIs:

- Organische Sitzungen
- Sichtbarkeit / Impressionen
- Klickrate (CTR)
- Durchschnittliche Position
- Conversion Rate aus organischem Traffic

Arbeitsrhythmus:

- Monatliche SEO-Analyse
- Quartalsweise Content-Updates
- Laufende Fehlerbehebung bei Crawl/Index-Problemen

## 16. SEO-Checkliste vor dem Veröffentlichen

- Hauptkeyword und Suchintention definiert
- Eindeutiger Title Tag vorhanden
- Meta Description optimiert
- Genau eine H1 gesetzt
- Logische H2/H3 Struktur
- URL kurz, sprechend, keywordnah
- Canonical korrekt
- Interne Links gesetzt
- Bilder optimiert inkl. Alt-Text
- Mobile Darstellung geprüft
- Core Web Vitals in akzeptablem Bereich
- Indexierung erlaubt (falls gewünscht)
- XML Sitemap aktuell
- Strukturierte Daten validiert

## 17. Glossar wichtiger Begriffe

- Crawl: Automatisches Auslesen von Seiten durch Bots
- Indexierung: Aufnahme einer Seite in den Suchindex
- Ranking: Position in den Suchergebnissen
- SERP: Search Engine Results Page
- CTR: Click Through Rate, Klickrate in den Suchergebnissen
- Canonical: Bevorzugte URL-Version einer Seite
- Duplicate Content: Sehr ähnliche oder gleiche Inhalte auf mehreren URLs
- Backlink: Externer Link von einer anderen Website auf deine Seite
- Anchor Text: Klickbarer Text eines Links
- Rich Result: Erweiterte Darstellung in Suchergebnissen (z. B. FAQ)

## 18. Priorisierung für den Start (80/20)

Wenn wenig Zeit da ist, zuerst diese Punkte umsetzen:

- Title, Meta Description, H1 und Suchintention pro Kernseite
- Interne Verlinkung auf Conversion-relevante Seiten
- Core Web Vitals und mobile Ladezeit verbessern
- Sitemap, Canonical, Indexierungsregeln sauber setzen
- Bestehende Top-10-Seiten inhaltlich aktualisieren

So entstehen in der Regel die schnellsten sichtbaren SEO-Effekte.
